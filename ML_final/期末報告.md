# Deep Q-Network (DQN) Implementation for PAIA

本專案基於 DeepMind 於 2015 年在 Nature 發表的經典論文 **"Human-level control through deep reinforcement learning"** [1]，並針對 PAIA 遊戲平台進行了架構調整。
以下詳細解析本專案使用的 DQN 核心數學架構、與原始論文的差異，以及 Loss Function 的推導過程。

---

## 1. 核心目標：最佳動作價值函數 (Optimal Action-Value Function)

DQN 的目標是訓練 Agent 學會一個策略 $\pi$，以最大化未來的累積獎勵。我們透過 **Bellman Optimality Equation** 來定義「最佳動作價值」：

$$
Q^{\ast}(s, a) = \mathbb{E}_{s^{\prime}} \left[ r + \gamma \max_{a^{\prime}} Q^{\ast}(s^{\prime}, a^{\prime}) \mid s, a \right]
$$

**符號定義：**
* $Q^{\ast}(s, a)$: 在狀態 $s$ 採取動作 $a$，並隨後都採取最佳策略所能獲得的最大預期回報 (Optimal Q-value)。
* $\mathbb{E}_{s^{\prime}}$: 對下一狀態分佈的期望值。
* $r$: 執行動作後獲得的**立即獎勵 (Immediate Reward)**。
* $\gamma$: **折扣因子 (Discount Factor)**，本專案設定為 **0.99**。決定了 Agent 對未來獎勵的重視程度。
* $s^{\prime}$: 執行動作後轉移到的**下一狀態 (Next State)**。
* $a^{\prime}$: 在下一狀態 $s^{\prime}$ 可能採取的動作。

---

## 2. 函數近似 (Function Approximation)

原始論文使用卷積神經網路 (CNN) 直接處理像素輸入，但由於 PAIA 平台可直接獲取物件座標，且為了適應高頻率的遊戲步調，本專案改用 **多層感知器 (Multi-Layer Perceptron, MLP)** 來逼近 $Q^{\ast}$ 函數：

$$
Q(s, a; \theta) \approx Q^{\ast}(s, a)
$$

**網路架構 (基於我們的架構):**
* **輸入層**: 8 維特徵向量 (球座標、速度、板子座標、障礙物座標)。
* **隱藏層**: 
    * FC1: 512 neurons (ReLU)
    * FC2: 256 neurons (ReLU)
    * FC3: 128 neurons (ReLU)
* **輸出層**: 動作維度 (Output Size)，對應每個動作的 Q 值。

**符號定義：**
* $Q(s, a; \theta)$: 我們訓練的 **Q-Network**。
* $\theta$: 神經網路當前的**權重參數 (Weights)**。
* $s$: 輸入狀態向量 $\phi$。在本實作中，$\phi$ 為一個正規化後的 **8維向量**：
  $$\phi = [\text{Ball}_x, \text{Ball}_y, \text{Ball}_{vx}, \text{Ball}_{vy}, \text{Paddle}_x, \text{Opponent}_x, \text{Blocker}_x, \text{Blocker}_y]$$

---

## 3. Loss Function 詳細推導

為了訓練網路，我們需要定義一個損失函數 (Loss Function) 來衡量預測誤差。本實作結合了 **Experience Replay** 與 **Target Network** 機制來穩定訓練。

### 步驟 3.1: 計算目標值 (The Target)

為了避免網路自我震盪（追逐移動的目標），我們使用一個獨立的 **Target Network** ($\hat{Q}$) 來計算未來的最大價值。

對於從 Replay Memory 中採樣出的第 $j$ 個經驗樣本，目標值 $y_j$ 計算如下：

$$
y_j = \begin{cases} 
r_j & \text{if } \text{done is True} \\
r_j + \gamma \max_{a^{\prime}} \hat{Q}(\phi_{j+1}, a^{\prime}; \theta^{-}) & \text{otherwise}
\end{cases}
$$

**符號定義：**
* $y_j$: 第 $j$ 筆樣本的**目標 Q 值**。
* $r_j$: 該步實際獲得的獎勵 (在本專案中包含擊球獎勵與勝負獎勵)。
* $\phi_{j+1}$: 下一步的狀態特徵向量。
* $\hat{Q}$: **目標網路 (Target Network)**。
* $\theta^{-}$: 目標網路的參數。它是每隔 `target_update` (1000) 步從主網路參數 $\theta$ 複製過來的（凍結參數）。

### 步驟 3.2: 損失函數 (The Loss Function)

我們希望主網路 $Q$ 的輸出能逼近上述的目標值 $y_j$。本專案使用 **均方誤差 (MSE)** 作為損失函數：

$$
L_i(\theta_i) = \mathbb{E}_{(\phi, a, r, \phi^{\prime}) \sim U(D)} \left[ \left( \underbrace{y_i}_{\text{Target}} - \underbrace{Q(\phi, a; \theta_i)}_{\text{Prediction}} \right)^2 \right]
$$

展開後的完整公式：

$$
L_i(\theta_i) = \mathbb{E}_{(\phi, a, r, \phi^{\prime}) \sim U(D)} \left[ \left( \underbrace{\left( r + \gamma \max_{a^{\prime}} \hat{Q}(\phi^{\prime}, a^{\prime}; \theta_i^{-}) \right)}_{\text{由 Target Network 計算}} - \underbrace{Q(\phi, a; \theta_i)}_{\text{由 Policy Network 計算}} \right)^2 \right]
$$

**符號定義：**
* $L_i(\theta_i)$: 第 $i$ 次迭代的損失值。
* $D$: **經驗回放池 (Replay Memory)**，本專案容量設定為 100,000。
* $U(D)$: **均勻分佈**。我們每次從 $D$ 中隨機抽樣 `batch_size` (1024) 筆資料來打破數據相關性。
* $\theta_i$: 主網路 (Policy Network) 的參數，這是我們透過梯度下降要更新的對象。

---

## 4. 梯度更新 (Gradient Descent)

為了最小化 Loss，我們對參數 $\theta$ 進行微分，得到梯度方向並進行更新：

$$
\nabla_{\theta_i} L_i(\theta_i) = \mathbb{E} \left[ \left( r + \gamma \max_{a^{\prime}} \hat{Q}(\phi^{\prime}, a^{\prime}; \theta_i^{-}) - Q(\phi, a; \theta_i) \right) \cdot \nabla_{\theta_i} Q(\phi, a; \theta_i) \right]
$$

**實作細節：**
* **Error Term**: 公式前半部 $(Target - Prediction)$ 代表了誤差的大小與方向。
* **Optimizer**: 雖然原始論文使用 RMSProp，但本專案使用 **Adam 優化器** (`lr=0.0005`) 來執行此更新，以獲得更快的收斂速度。
